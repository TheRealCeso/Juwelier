# Schriftlizenzen

Diese Website lädt ihre beiden Schriftfamilien lokal. Beide stehen unter der SIL Open Font License 1.1 und dürfen auch für kommerzielle Websites verwendet werden.

- **DM Sans** – Fließtext und Navigation. Lizenz: [OFL-DM-Sans.txt](OFL-DM-Sans.txt). Quelle: https://github.com/google/fonts/tree/main/ofl/dmsans
- **Playfair Display** – Überschriften. Lizenz: [OFL-Playfair-Display.txt](OFL-Playfair-Display.txt). Quelle: https://github.com/google/fonts/tree/main/ofl/playfairdisplay

Die Lizenz- und Urheberrechtshinweise liegen zusammen mit den eingebundenen Schriftdateien in diesem Ordner.
